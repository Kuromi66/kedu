# 刻度（Pulse）功能需求清单

本清单用于记录后续功能优化与新增需求，按优先级排序，逐个实现。

## 使用说明

- 每个需求有唯一编号（如 `F-01`），实现时以编号引用
- 优先级：P0（高，先做）/ P1（中）/ P2（低，打磨）
- 状态：`待办` / `进行中` / `已完成`
- 完成一个需求后，在下方「完成记录」表中登记

#### F-01 桌面小组件

- 目标：桌面直接查看今日打卡进度、快捷打卡；重要日期页展示下一个纪念日/交租日倒计时
- 要点：AppWidget + 数据刷新（Room 变化后同步更新）、深浅色适配、点击跳转对应页面
- 涉及：客户端

#### F-02 重要日期提醒

- 目标：在重要日期前 N 天发本地通知（如交租前 3 天、生日前 1 天）
- 要点：复用 WorkManager 通知体系，支持自定义提前天数；按月/按年循环日期也要生效
- 涉及：客户端

#### F-03 归档习惯管理

- 目标：补上「已归档」列表，支持恢复习惯与永久删除
- 要点：现在删除仅归档（隐藏）且无恢复入口；需新增归档页与永久删除确认
- 涉及：客户端、云同步（永久删除需墓碑或清理策略）

#### F-04 云同步国内可用性兜底

- 目标：Cloudflare 在国内不稳定，提供香港服务器自托管同一套 API 的兜底方案
- 要点：把 `cloud/` 的 Workers + D1 代码改造成 Node + SQLite 可部署版本，App 端仅换 API 地址
- 涉及：后端、客户端配置

#### F-05 账号体系完善

- 目标：邮箱验证、找回密码、注销账号
- 要点：后端增加验证/重置接口与邮件发送（或一次性重置链接），客户端设置页加入口
- 涉及：后端、客户端

#### F-06 修改打卡时间

- 目标：记录详情弹窗支持编辑时间，避免打错只能删了重打
- 涉及：客户端

#### F-07 通知快捷打卡

- 目标：每日提醒通知上带「打卡」动作按钮，不打开 App 直接记录
- 涉及：客户端

#### F-08 年度热力图 + 周视图

- 目标：统计页增加 GitHub 风格年度热力图；历史/统计增加周维度
- 涉及：客户端（统计计算 + UI）

#### F-09 导出 CSV / Excel

- 目标：在 JSON 备份之外提供 CSV 导出，便于用户自己分析
- 涉及：客户端

#### F-10 统计对比

- 目标：多习惯横向对比（完成率 / 连续），或同一习惯跨年对比
- 涉及：客户端（统计计算 + UI）

#### F-11 首次启动引导页

- 目标：利用现有 `onboardingSeen` 字段，首次启动展示 2-3 页引导
- 涉及：客户端
